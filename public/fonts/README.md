# Fonts
Place Gotham SSm woff2 files here:
- GothamSSm-Light.woff2
- GothamSSm-Book.woff2
- GothamSSm-Medium.woff2
- GothamSSm-Bold.woff2

Then add in src/styles/global.css:
@font-face { font-family:"Gotham SSm"; src:url("/fonts/GothamSSm-Book.woff2") format("woff2"); font-display:swap; font-weight:400 }
